Introduction

Welcome to the 3D printing brain project! In this guide, you will find detailed instructions to print a brain model successfully.

Step 1: Downloading from DARIS

    Login to Daris Using your Unimelb credentials. Your access will have to be approved prior to logon

    Daris is where teh radiographers upload all images collected from each scan

    Naviagte to the neuropaths folder (on the left hand side)

    If you have access to multiple projects all will be listed here

    Select the correct participant based upon their DARIS ID

    These can be found on the running participant tracker on the neuropaths drive Particiapnts that have been scanned multiple times will have multiple projects listed (each timepoint)

    Select the project you are after, it will open up all the scans collected

    The file we are looking for is listed as MP2RAGE (we will be using the file wihtout distortion correction)

Materials

  • 3D Printer
  • PLA or ABS Filament
  • Brain Model File (STL format)
  • Support Material (if necessary)
  • Tools for Assembly

Step-by-Step Instructions

  1. Prepare your 3D printer by calibrating it.
  2. Load the filament into the printer.
  3. Upload the brain model file to the printer.
  4. Print the model and wait for the process to complete.
  5. Assemble the parts carefully after printing.
